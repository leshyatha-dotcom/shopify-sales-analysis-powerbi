# Shopify Sales Analysis — Power BI Dashboard

An interactive Power BI dashboard analyzing Shopify sales data to uncover insights into transaction performance, customer purchasing behavior, and long-term customer value.

## Project Overview

This project analyzes a Shopify sales export (7,431 transactions) to answer key business questions around revenue trends, customer retention, and purchasing patterns — helping stakeholders make data-driven decisions on marketing, inventory, and customer engagement.

## Tools Used

- **Power BI Desktop** — data modeling, DAX measures, dashboard design
- **Power Query** — data cleaning and transformation
- **DAX** — custom measures for KPIs and time intelligence

## Key Features

- **Star schema data model** with a dedicated Date table
- **KPI cards:** Total Revenue, Total Orders, Average Order Value, CLV, Purchase Frequency
- **Trend analysis:** Revenue over time, orders by time of day
- **Product performance:** Revenue by product type, breakdown by first-time vs returning customers
- **Customer insights:** Unique customers, repeat purchase rate, top spenders, spend-tier segmentation
- **Interactive slicers:** Filter by Product Type and Date range

## Key Insights

1. Running Shoes are the top revenue-driving product category
2. Revenue peaks mid-week, suggesting optimal timing for promotions
3. 46% of customers are repeat buyers, with an average gap of ~2.73 days between first and second purchase
4. A small group of top-spending customers contributes a disproportionate share of revenue
